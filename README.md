# Network Traffic Analysis and Troubleshooting

## Project Overview
A network analysis project using Wireshark to inspect captured packets and understand communication between network devices.

## Objectives
- Examine TCP/IP communication.
- Identify DNS-related traffic.
- Observe IPv6 and ARP packets.
- Understand packet-level network communication.

## Tools Used
- Wireshark
- PCAPNG packet capture

## Packet Capture Summary
- Total packets: 189
- TCP packets: 105
- DNS-related UDP packets: 9
- IPv6 packets: 71
- ARP packets: 2

*Protocol counts may overlap because network-layer and transport-layer classifications describe different aspects of a packet.*

## Analysis Performed
- Examined TCP packets, including traffic involving port 443.
- Identified DNS-related UDP traffic.
- Observed IPv6 and ARP communication.
- Reviewed packet details to understand network protocols.

## Key Learnings
- Packet capture and protocol identification.
- Basic TCP/IP traffic analysis.
- DNS traffic inspection.
- Understanding IPv6 and ARP.

## Scope
The findings describe the packets present in the captured file. DHCP traffic and plain HTTP traffic were not identified in this capture.
